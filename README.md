# 🚿 세차현황 주간 대시보드

Excel 파일 업로드만으로 주차별 세차 현황이 자동 분석되는 웹 대시보드입니다.

## 주요 기능
- 📂 **Excel 업로드** → 자동 파싱 & DB 저장
- 📊 **주차 선택** → 2개 주차 나란히 비교
- 📈 **누적 트렌드** → WK22~WK99 전체 추이 한눈에
- 👤 **작업자 현황** → 이름 · 소속업체 · 완료건수 · 왕복/혼용 비율 · 평균 작업시간
- 🏢 **업체별 통계** → 대상/완료/완료율 + 세차경과일 구간(0-6·7-13·14-20·21일↑) 분포 + 작업인원
- 🤝 **제휴사별 통계** (신규) → 차량소속(제휴사) 기준 대상/완료/완료율/평균경과일/21일↑ 미조치
- 🚗 **차종별 통계** (신규) → 차종 기준 대상/완료/완료율/평균경과일
- 🗺️ **지역별 통계** → 시/도 + 구/군 세분화 상세
- 🧭 **세차대상 지도** (신규) → 메인 대시보드에 실제 대한민국 지도(SVG)가 표시됩니다. 대상차량 수 / 평균경과일 / 21일↑ 비율 토글, 지역에 마우스를 올리면 즉시 요약 툴팁, 클릭하면 해당 지역 차량 목록 팝업
- 🔁 **미조치 추적** → 이월 차량 자동 식별

## 🚀 Vercel 배포 방법 (15분)

### 1단계: GitHub에 올리기
```bash
git init
git add .
git commit -m "init: 세차 대시보드"
# GitHub에서 새 repo 만든 후:
git remote add origin https://github.com/YOUR_ID/carwash-dashboard.git
git push -u origin main
```

### 2단계: Vercel에 배포
1. [vercel.com](https://vercel.com) 접속 → GitHub 연동
2. **Import** → 위에서 만든 repo 선택
3. **Deploy** 클릭

### 3단계: Postgres DB 연결
1. Vercel 프로젝트 대시보드 → **Storage** 탭
2. **Create Database** → **Postgres** 선택
3. DB 생성 후 → **Connect to Project** 클릭 (환경변수 자동 설정)
4. **Redeploy** 한 번 더 실행

### 4단계: DB 테이블 초기화
브라우저에서 한 번만 접속:
```
https://YOUR-PROJECT.vercel.app/api/init-db
```
`{"ok":true}` 응답이 오면 완료!

> ⚠️ **기존에 이미 운영 중이던 대시보드를 이 버전으로 업데이트하는 경우에도** 배포 후 `/api/init-db`에 다시 한 번 접속해야 합니다. 제휴사/차종 통계용 신규 테이블과 업체·작업자 통계용 추가 컬럼이 기존 DB에 자동으로 반영되지 않기 때문입니다 (기존 데이터는 삭제되지 않습니다). 이후 업로드했던 주차들은 새로 업로드해야 신규 통계(제휴사·차종·경과일구간·작업자 소속 등)가 채워집니다.

## 📁 Excel 파일 형식

파일명에 `WK숫자`를 포함하면 주차가 자동 인식됩니다.
예: `WK24_세차현황.xlsx`

시트 구조는 `EXCEL_TEMPLATE_GUIDE.txt` 참고

### 세차대상 지도 업로드용 파일

주차 업로드와 별개로, **데이터 관리** 페이지에서 세차대상 리스트(전체 차량 스냅샷) 파일을 바로 올릴 수 있습니다. 업로드하면 메인 대시보드의 지도 카드에 반영됩니다.
`차량번호`, `지역(시/도)`, `지역(구/군)`, `세차경과일` 컬럼만 있으면 인식되고, `차종명`·`담당업체`·`차량소속`·`운영 BM`이 있으면 상세 정보도 함께 저장됩니다.
파일명에 6자리 날짜(예: `서버_260728.xlsx` → `260728`)가 있으면 스냅샷 라벨로 자동 사용되고, 없으면 업로드 시각 기준 날짜가 사용됩니다.
행정구역 명칭이 바뀌거나(강원도→강원특별자치도 등) 광주·전남처럼 통합되어도 자동으로 인식하려 시도하지만, 인식하지 못한 지역명은 지도 카드 하단에 "지도에 표시되지 못한 지역"으로 별도 표시됩니다.

지도에 쓰인 대한민국 시/도 경계 데이터는 [`@svg-maps/south-korea`](https://github.com/VictorCazanave/svg-maps) (CC BY 4.0, Victor Cazanave)를 사용했습니다 (`lib/koreaMap.js`).
